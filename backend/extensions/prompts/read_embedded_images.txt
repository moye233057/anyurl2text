你要从若干张图片中把文字读出来。这些图片是从一份文档里抽出来的内嵌图。

要求：
1. 每张图独立处理，逐字读出该图中的所有文字，保持原有阅读顺序；表格按行列还原。
2. 只输出图中真实存在的文字：不总结、不解释、不翻译、不补全、不加图外的背景知识。
3. 看不清的地方标注「[看不清]」，不要猜测。
4. 某张图确实没有文字时，该条 text 用空字符串，不要编内容。

按下面的 json 结构输出，index 必须与给定图片的序号一一对应，不要输出任何其它内容：
{
  "images": [
    {"index": 1, "text": "第 1 张图的文字"},
    {"index": 2, "text": "第 2 张图的文字"}
  ]
}
