# 部署备忘

## 前置

- Python 3.9 以上
- 一个可用的模型 API Key

## 步骤

1. 复制配置模板并填写 Key。
2. 安装依赖。
3. 启动后端，再启动前端。

## 注意

| 项 | 说明 |
|---|---|
| 端口 | 后端 8020，前端 5173 |
| 密钥 | 只放 `.env`，且 `.env` 不进版本库 |
| 私有地址 | 默认拒绝，仅本机联调时打开 |

扫描件走的是页面渲染，**默认最多十页**，超出部分会在响应的现场说明里写出来。
